# SecondSelf Frontend

React + Vite frontend application for SecondSelf Windows AI Digital Twin prototype.

## Setup Instructions

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

## Features
- **Header component**: Displays project title and Windows platform target.
- **HealthStatus component**: Dynamic status monitor that polls backend `GET /api/health` and shows live connection state.
- **Modular Architecture Preview**: Highlights active foundation components and future expansion placeholders.
